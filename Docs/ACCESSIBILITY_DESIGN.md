# ERİŞİLEBİLİRLİK (kayıt)
## Kontroller: joystick boyut+konum ayarı; tüm tuşlar yeniden konumlandırılabilir; boyut+şeffaflık; sol/sağ el düzenleri; çoklu kayıtlı profil; tek dokunuş varsayılana dönüş.
## Kamera: hassasiyet; uzaklık seçenekleri; takip hızı; otomatik kilit aç-kapa; sarsıntı azaltma; Y-ekseni ters çevirme.
## Görsel: altyazı aç-kapa+boyut; UI yazı okunabilirliği; saldırı uyarısı yalnız renkle değil (simge+görsel işaret); parlama/sarsıntı/yoğun efekt azaltma; renk körlüğü dostu arayüz seçenekleri.
## Ses+titreşim: ana/müzik/ortam/efekt/diyalog ayrı ayar; titreşim tam kapatma; hafif/normal/güçlü profiller; saldırı ağırlığı haptik sistemi korunur; sessiz oyuncular için kritik uyarılar görsel de gösterilir.
## Yardımcı: eğitim tekrar oynatılabilir; savaş sırasında kontrol görüntüleme; ANTRENMAN ALANI (sandbox pratik); ipuçları aç-kapa (deneyimliyi rahatsız etmez); kolaylık/zorluk seçeneği varsa dengeyi bozmaz; hikâye tamamlanması gerçek paraya bağlanmaz.
## Kayıt: otomatik; yeniden açılışta korunur; kontrol düzeni ve grafik AYRI kategorilerde; bozuk/eksik ayar güvenli varsayılanla onarılır; sıfırlama seçeneği.
## Testler: farklı ekran boyutu/performans seviyesi; küçük ekranda tuş çakışması; yazı okunabilirliği; ayar kaybolması kontrolü.
## Not: grafik profili/FPS/parlaklık/titreşim kademesi SCREEN_SETTINGS ile BİRLEŞTİ; çift tanım yok. Faz: temel kontrollerle F5; tam set F9-11.
