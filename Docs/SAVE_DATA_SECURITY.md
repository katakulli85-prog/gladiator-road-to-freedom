# KAYIT VE VERİ GÜVENLİĞİ (kayıt)
## Kayıt: savaş ilerlemesi; açılan karakterler; ekipman; para; görev; başarım güvenilir kaydedilir; önemli noktalarda otomatik kayıt; kapanınca son güvenli noktadan devam; kayıt sırasında çökme → bozulma önlenir (ATOMİK: yaz→doğrula→eskiyi yedeğe al→yer değiştir); 3 nesil yedek zinciri (ana+yedek+yaşlı) — "son sağlam kayda dön".
## Bütünlük: yüklemede şema+aralık doğrulama (negatif altın; sınır aşımı seviye; tutarsız ilerleme tespit); bozuk → son sağlam yedekten yükle; normal ilerleme yanlışlıkla silinmez.
## Satın alım güvenliği: yalnız doğrulanmış işlem teslim eder; başarısız/bekleyen/iade yönetimi; işlem kimliği defteri (çift ödül yasak); Google doğrulama; ileride Apple desteği; 1.0'da ayrı sunucu YOK (Google acknowledgment yeterli — karar); anahtar koda gömülmez.
## Çevrimdışı: ana oyun internet istemez; çevrimdışı kayıt güvenli; satın alım/doğrulama kuyruğu bağlantı gelince TEK atomik adımda senkron (çift ödül/kayıp yasak).
## Gizlilik: gereksiz kişisel veri toplanmaz; analitik/reklam uyumlu; gereksiz paylaşım yok; ileride bulut kayıt gelirse hesap güvenliği tasarlanır. (Play gizlilik politikası taslağı F13.)
## Test matrisi: kayıt bozulması; ani kapanma; cihaz yeniden başlatma; satın alım tekrar işlenmesi; internet kesintisi; senkron.
